# 原神 · 无名杀扩展

基于无名杀 v1.11.6 的原神同人武将扩展，包含原创技能、配套立绘、中文语音与游戏 AI 策略，持续维护更新。

## 武将卡图

前往 **[实体武将卡图](physical-cards/README.md)** 浏览卡图。该目录用于展示武将牌面，与游戏内角色立绘分开存放，已收录原神从开服到月之八版本的大部分五星角色。  
目前尚未收录的五星角色：提纳里，赛诺，艾尔海森，流浪者，迪希雅，杜林。

## 安装与更新

1. 下载本仓库（Code → Download ZIP）并解压。
2. 在`你的无名杀目录/resources/app/extension/`下新建`原神`文件夹，将此页面的扩展文件放入无名杀的 `extension/原神/` 目录，确保 `extension.js` 直接位于该目录下。
3. 在游戏中启用「原神」扩展，重启游戏。

更新前备份本地修改，再用新版文件覆盖扩展目录并重启。当前以 v1.11.6 为开发基准，其他版本的兼容性尚未全面验证。

- 问题与建议：[GitHub Issues](https://github.com/Xixingsiuuz/noname-genshin/issues)。反馈时请附引擎版本、相关武将及复现步骤。
本项目为非官方同人扩展；角色及相关美术、语音素材的权利归各自权利人所有。

## 检查更新

在游戏的「扩展 → 原神」设置中点击「检查更新」。默认开启「启动时检查更新」，发现更高版本的 GitHub 正式 Release 后提示，同一版本只自动提醒一次。可前往发布页下载新版，覆盖扩展目录后重启。网络检查失败不影响游戏；启动检查失败时不弹窗。
