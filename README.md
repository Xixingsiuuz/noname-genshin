# 原神 · 无名杀扩展

基于无名杀 v1.11.6 的原神同人武将扩展，包含原创技能、配套立绘、中文语音与游戏 AI 策略，持续维护更新。

## 武将卡图

前往 **[实体武将卡图](image/character/cards/README.md)** 浏览卡图。该目录用于展示武将牌面，与游戏内角色立绘分开存放。

## 安装与更新

1. 下载本仓库（Code → Download ZIP）并解压。
2. 将扩展文件放入无名杀的 `extension/原神/` 目录，确保 `extension.js` 直接位于该目录下。
3. 在游戏中启用「原神」扩展，重启游戏。

更新前备份本地修改，再用新版文件覆盖扩展目录并重启。当前以 v1.11.6 为开发基准，其他版本的兼容性尚未全面验证。
