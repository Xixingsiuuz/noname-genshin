# 原神 · 无名杀扩展

基于无名杀 v1.11.6 的原神同人武将扩展，包含原创技能、配套立绘、中文语音与游戏 AI 策略，持续维护更新。

## 武将卡图

前往 **[实体武将卡图](physical-cards/README.md)** 浏览卡图。该目录用于展示武将牌面，与游戏内角色立绘分开存放，已收录原神从开服到月之八版本的大部分五星角色。  
目前尚未收录的五星角色：杜林。

## 安装与更新

1. 下载本仓库（Code → Download ZIP）。
2. 可以用名称带有“DirectImport”的包在无名杀的【选项-扩展-获取扩展-导入扩展】内直接导入；也可以将其他压缩包解压，将文件夹内的`extension.js`目录下的所有文件重新压缩，使用无名杀的【选项-扩展-获取扩展-导入扩展】导入新的压缩包；也可以**万能导入法**，在【选项-扩展-制作扩展】处新建一个空扩展，命名“原神”然后保存，然后用压缩包内`extension.js`目录下的所有文件替换`你的无名杀目录/resources/app/extension/原神`文件夹的内容。
3. 在游戏中启用「原神」扩展，重启游戏。

当前以无名杀 v1.11.6 为开发基准，旧版本的兼容性尚未全面验证。

## 检查更新

在游戏的「扩展 → 原神」设置中点击「检查更新」。默认开启「启动时检查更新」，发现更高版本的 GitHub 正式 Release 后提示，同一版本只自动提醒一次。可前往发布页下载新版，覆盖扩展目录后重启。网络检查失败不影响游戏；启动检查失败时不弹窗。
