# 七七实现记录

已注册 `fan_qiqi`：魏势力，女性，3体力／3体力上限／3护甲，称号“冻冻回魂夜”；技能为度厄、回骸，含AI、十条指定中文原声与独立三处立绘。用户已确认允许自救、采用原生休整时点，并指定参考十常侍。

## 已核对的本地 v1.11.6 节点

- `phaseDrawBegin1`：将本次摸牌数量改为0且固定，然后亮出牌堆顶五张；固定摸牌事件不触发替换。
- 亮牌进入处理区后公开展示，黑色牌公开获得；X按亮出的黑色牌快照计数，不按后续仍在手中的张数计数。
- 获得及其触发完成后可选1至X名尚无真符的角色，允许自己；可取消授符，已经完成的替换摸牌和得牌不撤销。
- 授符按当前回合角色起的座次顺序，实际授予前再检查；剩余处理区牌无论正常或异常退出均移入弃牌堆。
- 真符作为独立后续效果挂于受益者；不叠加，不要求七七继续持有度厄或仍在场。确认发动回骸时，若获救角色已有真符，则通过本次死亡事件的 `excludeMark.add("fan_due_zhenfu")` 保留原有图标与提示；不重建、不重新授予真符，也不豁免其他标记或实体牌的死亡清理。回归后正常消耗真符时图标同步移除。
- `damageSource` 是本地伤害流程末端的来源节点。实际伤害大于0才消耗真符，先移除再回复1；多点伤害只回复1，满体力仍消耗，自伤与连环造成的实际来源伤害均可触发。
- 原生 `rest({type:"round",count:1})` 在休整者下个正常回合开始前回归；额外回合不计入。原生默认回满，回骸需另行确保调整到2再摸2。
- 回骸参照本地十常侍 `mbmowang`：`dieBefore` 确认发动、立即消耗本局限定资格并设置 `reserveOut` 和 `noDieAudio`；`dieAfter` 才实际调用休整。不能把前置预留描述为死亡被取消或已回到场上。拒绝发动不消耗资格、不设置预留、不播回骸。
- 原生死亡仍执行死亡记录、体力归零、`die` 触发和区域牌清理；`reserveOut` 跳过模式的 `player.dieAfter` / `player.dieAfter2`（含身份判负及模式击杀奖惩）、正式死亡动画和武将回池，沿用十常侍语义。休整分支不播放正式阵亡语音，未发动或限定资格已用后的真实死亡走三条“倒下”随机池。七七可以在自己死亡流程中确认发动。
- 回骸的后续效果独立挂于获救角色的 `fan_huihai_rest`，不依赖七七继续在场或保有技能。`dieAfter` 只接收已预留的本次死亡，播放一次元素爆发原声后 `rest({type:"round",count:1})`；休整期间嵌套死亡参照殁亡取消，不重复消耗或播放。
- 回归仍使用原生 `restEnd` / `reviveEvent`；在 `restEnd` 调整体力后摸两张，并先清除一次性返回状态以防嵌套重复。调整使用 `changeHp`，不会当作回复或失去体力触发相应技能；体力上限不足2时遵守当前上限，不增加上限。回归后的正常回合照常进行。
- 限定资格存储在 `fan_huihai_used`；不因休整、回归、跨回合或显示更新刷新，`limited` / `awakenSkill` 仅配合原生展示。预留确认后该次发动已消耗，不在返回时才消耗。
- AI：度厄按本次原摸牌数及可授符收益评估；真符结合敌友、伤势、出伤资源，回骸允许自救、偏向救队友，拒绝敌方；限定状态在过滤及确认后均再次检查。AI偏好不限制玩家救敌方或给敌方真符。

## 验证

`node tests/qiqi.mjs`：替换、亮牌、得牌、剩余牌清理、座次、取消、全红、离场、独立真符、多点及满体力消耗的节点模拟。
`node tests/qiqi-rest.mjs`：从实际挂载技能派发触发，直接执行本地原生 die / rest / restEnd / revive / _rest_return 方法体，验证自救、救队友、取消、敌方AI、死亡清牌、预留跳过模式回调、额外回合排除、七七离场后独立回归、重复触发拒绝与低上限。开启原生死亡标记清理（`reserveDead:false`），覆盖自救及救其他角色时保留同一真符标记节点、无真符不创建、取消不豁免清理、其他标记照常清除、回归后造成伤害消耗并移除图标且只回复一次。仍为受控测试替身环境，不是真实对局。
`node tests/qiqi-audio.mjs`：十条源文件与播放文件哈希、峰值、原生音频路径和台词解析、日志无声、分支播放、语音开关及三条阵亡池。
立绘：独立选将近景、对局半身、详情完整取景，保留原画；可复现工具 `tools/prepare_qiqi_portraits.py`；参数在 `image/character/originals/qiqi-crops.json`，预览为同目录 `qiqi-review.png`。
