# 神里绫人：三行、兴家

最新技能栏以2026-10-25用户最后上传的卡牌图逐字录入。男、魏、4体力，角色ID fan_ayato；技能为 fan_sanxing、fan_xingjia。旧技能已更名；不为未确认的旧对局兼容保留旧ID，须重启并新开对局加载。原画及裁剪立绘不变。

## 三行

监听 gainAfter / loseAsyncAfter 与自身 damageEnd。得牌以该次原持有者失牌 cards2 与目标实际 getg 的交集确定；不再因绫人回合内的其他来源得牌触发。批量移动排除 getlx=false 的内部事件，多名得牌者以 sortBySeat(_status.currentPhase || player) 排序，内容读取本地引擎真实传递的 indexedData，处理前复查仍在场。

“这些牌”包括本次从绫人获得的牌以及三行追加交出的一张：原得1张+追加1张，须交回4张；原得2张+追加1张，须交回6张；颜色取这批牌的并集。伤害触发没有原得牌，只计算追加1张，须交回2张。一次多点伤害仅发动一次，自伤、失去体力、无来源伤害和来源已离场不发动。

交回不足时保留“交给手牌”按钮，使用原生 textbutton / filterButton 将其标为 unselectable，原生CSS以0.6透明度显示禁用。实际选牌须足额，交付前再次核对全部实体牌仍在手牌区。弃置统计手牌和装备区同色且可弃的牌，不含判定区。三行的追加交牌及交回事件带 fan_sanxing 标记，所有三行拥有者均排除这些直接移动，其他技能独立引起的得牌不一概屏蔽。

## 兴家

主技能通过原生 global: fan_xingjia_visit 提供其他角色出牌阶段的行动按钮，不在扩展content中提前注册未定义技能。由行动角色决定是否发动，绫人不能替其发动。每名行动角色每个出牌阶段限一次，原生 phaseUse 内容重置主动技能统计；多名兴家拥有者时共用此行动次数，不按目标重复使用。确认发动前可以取消且不消耗次数；一旦确认并进入观看手牌界面，必须获得一张合法手牌，不可取消，不退还次数；确认后按规则消耗，不因随后三行弃掉刚得的牌而退还。

观看手牌与选择获得合并在原生 choosePlayerCard visible + forced 流程中，不设置 fanPairedConfirm 以免公共UI强行加入取消按钮，只向操作者展示。既定绫人目标无需在看牌界面重选。不能获得的牌由原生 canBeGained 过滤，实际获得前再次核对。只有绫人当前持有且生效的兴家可以被选择，自己、空手或没有可获得手牌者不可选。

顺序：确认获得绫人一张手牌 → gainAfter → 三行询问与全部处理 → 原gain完成 → 绫人摸2张。三行可以放弃，放弃不取消兴家的补牌；三行把已获得牌弃掉或交回也不取消补牌。观看后若角色离场或所有合法牌失效则终止，不强行获得失效牌，已观看不退还次数；得牌替换导致实际上未获得所选牌则不补牌；绫人已离场不摸牌。

AI：绫人按追加牌颜色、对方弃牌与足额交回成本、敌友决定三行；对方从合法选项中选择代价较低者。兴家协助队友，敌人同时考虑让绫人摸2张与三行的索偿风险；不通过规则禁止敌人发动。未观看前只用公开明置牌评估具体牌，并保守估计暗牌风险，不通过扫描暗置手牌决定是否发动。选择界面中按已观看牌评价。每次选择按最新资源评估。

## 验证与待实测

tests/ayato.mjs 模拟从持有技能展开三行触发器，使用 indexedData 而非伪造 targets；从兴家主技能 global 关系展开行动定义。覆盖得牌红黑合集、6张交回、伤害2张交回、直接移动排除、原回合内额外触发取消、灰色按钮过滤的动态数量校验、取消、离场、兴家得牌至三行至补牌顺序、不可获得牌、失去技能及敌友AI。模拟的gain会先派发得牌触发器再完成，避免省略关键嵌套。

JavaScript语法与模拟回归不代表真实对局实测。需实测：新行动按钮显示与阶段限次、实际灰态/不可点击、观看隐私、实际语音、嵌套得牌与伤害、技能封锁、多个绫人及额外出牌阶段。
