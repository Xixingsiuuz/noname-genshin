# 流浪者实现说明

男，魏，3体力，1护甲；语音已按使命状态接入，详见 audio/README.md。原画及归一化裁剪坐标保存于 image/character/originals/wanderer*。

- 失心：damageEnd 记录实际伤害来源；不统计失去体力或被防止的伤害。目标修正放开距离和次数资格，仅当全部目标均为已记录来源时退还本次正常用牌计数。混合目标仍正常计次。
- 寻神：得失牌移动事件完成后调整至2，使命失败后至4。以原生摸牌和强制弃牌完成调整，遵守引擎弃牌禁令；因此移动过程中不是数学意义上的恒定手牌数。本地神赵云没有恒定4手牌版本，未宣称直接复用其技能。
- 摸牌阶段：phaseDrawBegin2 先失去体力，再少摸2；因此可能先触发濒死成功。成功获得的问道不追溯加入已经展开的本次触发列表。
- 根除：damageSource；双方区域按hej。只检查自己有合法可弃牌即可询问；取消不耗次数。先弃自己，再按目标最新状态弃其一张，无牌跳过。自己的弃牌引发寻神调整后才处理对方。使命结果不移除每回合弃牌分支。
- 使命：source dieAfter 失败（寻神调整至4）；player dying 成功，先记录结果防止重复，再回复至1，失去寻神并获得问道。成功失败互斥。
- 问道：移动结束后仅补足至2，摸牌阶段先回复1再增加2摸牌。

验证：node tests/wanderer.mjs 模拟检查手牌调整、成功失败互斥、替换技能、标记目标、计数豁免、限次刷新。所有修改的JS通过node --check。未运行真实对局；自动确认开关、禁弃牌交互、原生触发排序和三处立绘界面仍需游戏实测。
