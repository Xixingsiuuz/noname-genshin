# 莫娜

魏，女，3体力、1初始护甲，称号“星天水镜”。技能栏逐字保留用户卡面文本，未添加锁定技字样。

- 激流：`useCardToTargeted`，其他角色使用牌使莫娜成为目标后累加1。距离修正为全体其他角色到莫娜的单向距离，莫娜到他人不变。每次成为目标独立累计；不撤销已指定的目标、不减少当前牌效果、不要求伤害，也不由铁索传导伤害触发。标记在莫娜自己的 `phaseAfter` 清除，其他人的回合结束不清除；莫娜回合内获得的层数也于该回合结束清除。
- 水镜：`phaseZhunbeiBegin` 选择观看牌堆顶、摸牌或取消。确认后立即记录另一项，再执行所选项；`phaseJieshuBegin` 强制执行另一项，先移除待执行记录，避免重复触发。跳过准备阶段不会新建后续项，跳过结束阶段不会补做，当前回合结束移除记录。重复准备阶段分别记录对应后续项。
- 两个主技能均 `locked:false`。技能被封锁时不再新增激流层数或发动水镜；已经产生的距离效果和已安排的水镜后续作为独立的 `charlotte` 状态保留，暂时失效不清空、也不刷新。失去主技能同样不撤销已生效的后续效果。
- 水镜观看仅对操作者显示，五张牌全部在同一行自由排序，不允许放到底部；左侧第一张即新的牌堆顶。实际不足五张时处理引擎可取得的牌。使用原生 `chooseToMove(true)` 与 `cardsGotoPile(...,"insert")`，逆序逐张插顶，保留最终指定的顺序；异常退出也将仍在处理区的牌放回顶端。没有替换手牌操作。
- 激流每次实际触发由原生技能音频随机播放一条。水镜两次实际执行各随机播放一条，准备阶段询问和记录不播音，取消不播音。阵亡三条由原生 `dieAudios` 随机。详情页两技能及阵亡字幕均对应实际播放文件。
- AI：激流仅加入较小的后续防护收益，不令当前用牌无效，不禁止队友收益牌。水镜通常优先整理自身判定和摸牌；1体力且无桃酒时优先拿牌。整理按实际判定顺序优先配置，再按摸牌价值排列；结束阶段整理参考下家敌友关系。每次执行重新评估实际牌与目标状态，不偷看未展示的牌堆。
