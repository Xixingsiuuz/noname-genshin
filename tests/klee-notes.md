# 可莉：实现与验证

武将 `fan_klee`，女，蜀，3体力、1护甲，称号“逃跑的太阳”。牌面文本录入 `character/translate.js`；原图保留在 `image/character/originals/klee.png`，头像按 `(680,60,2280,2300)` 裁剪为400×560。2026-10-26按对局截图反馈将人物向右移动30像素（头像宽度的7.5%），保持缩放与上下取景不变，已检查脸部及上半身；未进入游戏复测。

## 结算

- 火花：本次实际用牌事件为可莉使用的杀，且伤害来源为可莉、受伤者不是可莉时触发。不排除铁索传导，不按敌友过滤；一次多点伤害只触发一次。
- 逃跑：`useCardToTarget` 使用原生流离同一时点与目标合法性接口，弃置一张可弃手牌或装备。联合选择支持先牌后目标、先目标后牌、取消和确认禁用。多目标杀仅替换可莉，不改变使用者，不限制原使用者到新目标的攻击距离；新目标须在可莉攻击范围内、不是用牌者、不是现有目标且符合目标禁用规则。范围在支付前核对；与原生流离一致，弃武器不撤销确认时合法的目标。
- 实际支付后，独立辅助技能将附加效果绑定此 `useCard` 事件；此杀伤害任何角色及铁索传导均触发，包括队友和可莉。可莉不承受其自身技能溅射，但仍可承受其他角色传导的属性伤害。
- `damage` 节点在扣血后、濒死前保存上下家；`damageSource` 在濒死处理后结算溅射，早于原生 `damageAfter` 铁索。致死伤害使用上述快照；两邻居去重、排除可莉，以当前回合角色起座次依次处理，每人结算前复查在场。首人的伤害完整结算后再处理第二人，不补选新邻居。
- 溅射显式 `damage(1,"fire",可莉,"nocard")`，不继承外层杀的牌归属；它可以正常引发铁索，但该技能伤害及其传导不再触发火花。溅射可能抢先使其他横置者重置，使其不再承受原杀的后续传导，不改写原生铁索规则。
- 每个用牌事件独立，嵌套追杀和同一实体牌再次使用不继承效果；嵌套 `useCardAfter` 不清除外层效果。已赋予的牌效果不因逃跑随后失效而撤销，正确用牌结束时清理。火花锁定、逃跑非锁定。
- AI计入转移前后伤害、弃牌价值、相邻敌友火焰伤害及属性连环的折减预期；火花保留原牌命中、目标与用牌者收益。属于收益启发式，不保证完整预测其他武将复杂嵌套技能，规则过滤不按敌友限制操作。

## 验证范围

2026-10-26修复命中杀时报 `fan_huohua_record: ReferenceError: snapshot is not defined`：原记录器为普通 `content`，本地 `StepCompiler` 会通过函数构造器重建其函数体，失去模块闭包；改为 `async content`，使其通过保留原函数的 `AsyncCompiler`/`ArrayCompiler` 执行。规则、AI和语音池不变。

`tests/klee.mjs` 现加载本地五个原生编译器类，技能记录、伤害结算、逃跑交互和附加效果均经过编译执行，而非直接调用内容函数；保留修复前的普通函数版本，断言其实际编译执行会抛出同一个 `snapshot is not defined`。事件步骤模拟沿用本地延迟写入step的语义，沙盒构造器选择使用普通Function，报错片段登记为诊断替身；不宣称已经验证真实游戏沙盒或界面。

`node tests/klee.mjs`：按持有技能展开分组和动态附加技能派发事件；复用本地 `Player.damage()` 和 `_lianhuan.content` 方法体，覆盖无牌技能伤害、实际传导牌归属、溅射抢先传导、伤害为零、自伤、死亡邻居快照、座次、邻居离场、去重、每次一次语音、联合选择、取消、支付失败、多目标、嵌套事件隔离、失效后既成效果和到期清理、敌友AI。

`node tests/audio-layout.mjs`、`node tests/skill-voices.mjs`：原生音频解析、技能与阵亡台词、随机池、静音开关、路径、字节与哈希、详情汇总不改播放池。

以上为方法体复用与模拟验证，不能替代真实游戏。尚未进入对局验证选择界面、转移后目标触发、铁索及濒死嵌套、联机和实际播放；尚未人工试听，用户本地语音台词依据文件名记录。
