# 甘雨：结算、语音与验证

魏，女，3体力、1护甲，称号“循循守月”。三个技能均非锁定技，技能栏保留卡图原文。

## 规则节点

- 流天：蓄力初始1，上限2，使用本地原生蓄力接口。出牌阶段限一次，支付前复核足额，消耗1点后获得本回合待用效果。不要求当时已经有杀。AI只在有合法且对自身有利的杀时主动支付，会考虑正常次数额度、无距离限制后的目标、敌友和目标禁用。
- 下一张杀选目标时无距离限制，仍检查次数、禁用及其他目标合法性；正式使用时在 `useCard` 给本次事件 `baseDamage + 1`，同时移去待用效果。多目标和同张杀的额外结算沿用本次基础伤害；独立嵌套杀不继承。目标被取消、闪避或伤害被防止不返还强化。未用出则回合结束清除。
- 麟迹：其他角色 `phaseZhunbeiBegin` 选择摸牌或获得1点蓄力，可取消；确认并复核后消耗本轮一次资格。每轮共一次，按 `game.roundNumber` 比较，不因下一回合而刷新。满蓄力时保留获得蓄力选项但不可选择，结算前也复核。
- 先完成摸牌或获得蓄力，再建立本回合关系。**只有该角色到甘雨的距离+1，甘雨到该角色不变**；只禁止该角色对甘雨使用顺手牵羊，其他角色不受影响。效果在该回合结束清除。摸牌产生的嵌套触发发生在关系建立前。
- 星佐：其他角色 `phaseDiscardEnd`，查询本回合已完成伤害记录；该角色曾作为来源对甘雨造成正数伤害则不发动，其他来源或失去体力不因此禁止。收集本阶段所有角色因弃置失去、当前仍在弃牌堆的实体牌，排除别的阶段和用牌素材。可选一张，取消无事发生，获得前重新核对位置及伤害条件，不能换成未展示的牌。
- 按本地 `content.js` 核对 `baseDamage` 在 `useCard` 之前初始化；按 `get/index.js` 核对 `globalTo` 只修正到技能持有者方向。选项使用原生 chooseButton；`selectButton: [0,1]` 配合最终恰好一张校验，避免原生单选自动确认，复用确定/取消控件。

## 验证范围

`node tests/ganyu.mjs` 覆盖本地原生蓄力方法、初始与上限、足额支付、使用事件绑定、目标取消、单向距离、顺手禁止、每轮一次、取消、选择后状态变化、弃牌阶段归属、移走的牌、伤害来源及AI敌友/禁用/距离/次数/资源变化。主技能从武将定义检查可达，没有未挂载记录器。

`node tests/audio-layout.mjs` 与 `node tests/skill-voices.mjs` 验证原生音频路径、字幕、原生解析、音频开关、文件哈希与详情汇总不改变播放列表。三套取景独立保存，完整原图保留；选将通过原生 character 按钮预设应用近景，对局将框读取主头像，详情弹窗读取较完整高分辨率取景。

以上为模拟、静态路径检查与音频测量；尚未人工试听、游戏内三处显示、联机或实际对局验证。
