# 武将 AI 收益递归排查

检查 character/skills 中 ai.effect 的 player、target、player_use、target_use 及其间接调用的收益辅助函数，同时检索 get.effect、damageEffect、recoverEffect、getUseValue 等调用。普通选择用的收益调用不等同于递归；按是否会回到正在执行的技能评估判断。

补充防护：

- 优菈 fan_langhua：额外伤害估值调用原生 damageEffect，若虚拟伤害牌的点数仍经其他修正满足浪花计数条件，可能重入同一评估。按拥有者限制嵌套重入，最外层保留完整估值。
- 茜特菈莉 fan_yingxin_share：共享素材的空手收益会调用原生 losehp 估值。增加同一拥有者的重入保护，避免其他评估交互再次分析同一共享手牌收益。

这是对可重入路径的保护，不宣称这两名角色在普通对局中已复现与公子相同的报错。finally 负责清理，后续独立评估不受抑制。游戏规则、合法性和实际技能结算不变。

其他已复核的收益路径包括绫华、甘雨、琴、可莉、心海、申鹤、魈、夜兰、宵宫、胡桃、七七、莫娜及妮可等；固定牌名/类别检查、既有重入保护或素材匹配可使嵌套评估退出。暂未确认同类无保护循环，不代表所有武将组合已穷举。

tests/ai-recursion-audit.mjs 覆盖两处嵌套原生估值回调模拟、反复独立评估和异常清理。相应既有武将模拟测试及 JavaScript 语法检查用于回归；尚未真实对局验证。测试中的旧字符表字符串加载方式已改为实际模块导入，以兼容其当前 smoothPortraits 依赖。
