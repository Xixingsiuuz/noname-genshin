## 手牌自动排序

启用扩展后，可在“原神”的扩展设置中开启“手牌自动排序”（默认关闭，设置自动保存）。开启时立即整理自己的手牌，并在获得牌、批量牌移动结算后、起始发牌结束及回合开始时再次整理；适用于所有武将。关闭后停止自动整理。

排序调用原生 `sortHandcardOL(_status.tempHandcardSort)`，与“整理手牌”按钮使用相同规则，不改变武将技能。尚需在实际游戏中验证发牌、摸牌、交换手牌及开关效果。

## 文件组织

```text
extension.js                 扩展入口及基本配置
info.json                    扩展元信息
character/
  index.js                   组装武将包与技能包
  character.js               武将 ID、性别、势力、体力、初始技能、立绘路径
  skill.js                   汇总各角色的技能模块
  translate.js               武将名称、技能名称与技能描述
  skills/
    furina.js                芙宁娜的技能实现（含子技能、衍生技能）
image/character/
  furina.avif                芙宁娜立绘
```

## 添加武将

1. 在 `character/character.js` 中添加武将定义，使用唯一的武将 ID 和技能 ID。
2. 在 `character/skills/` 下创建角色技能模块，以 `export default { ... }` 导出技能对象。该目录引用游戏 API 的路径为 `../../../../noname.js`。
3. 在 `character/skill.js` 中导入新模块，并将技能对象展开到汇总对象。各模块的技能 ID 不得重复，否则后面的定义会覆盖前面的定义。
4. 在 `character/translate.js` 的 `characterTranslate` 中添加武将名称，在 `createSkillTranslate()` 返回的对象中添加技能名称和描述。
5. 将立绘放入 `image/character/`，在武将定义中登记 `ext:原神/image/character/文件名`。
6. 对修改的 JavaScript 文件运行 `node --check 文件路径`，再进入游戏验证武将加载和技能结算。

`createSkillTranslate()` 在扩展工厂执行时生成描述，保留 `get.poptip()` 原有调用时机和原生悬停提示。模块由入口静态导入，仍通过原有的 `package.character`、`package.skill` 注册，无须再次调用 `game.import()`。

选项4登记至目标下个实际开始的摸牌阶段，将该阶段因摸牌而获得且仍在目标处的牌立即转交给发动者；阶段内额外摸牌也适用，直接获得或他人交给的牌不计。跳过摸牌阶段不消耗登记，但目标自己的回合结束仍会清除；发动者离场则不转交。选择自己不会移动牌。多名莱欧斯利的取牌效果按施加顺序处理，不重复转交同一张牌。转交在 `gainAfter` 结算，目标先获得牌，仍可触发获得牌技能。
