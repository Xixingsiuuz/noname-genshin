# 原神扩展 v0.2.1

适用于无名杀 v1.11.6。

## 新增

- 扩展设置新增「检查更新」按钮及「启动时检查更新」开关。
- 检测 GitHub 最新正式发布版本，发现新版时展示版本号、更新说明与下载入口；同一版本只自动提醒一次。
- 自动检查失败时不打扰游戏，手动检查可查看失败提示。

## 修复与优化

- 雷电影：修复转化响应提交后确认控件未清理的问题，并在提交前再次检查事件和素材合法性。
- 丝柯克：修复「剑流」转化杀的次数豁免，使其既不消耗正常使用次数，也能在正常次数用尽后使用。
- 希诺宁：修正 AI 出牌顺序评估的回调参数。
- 新版钟离：修复「契」标记的卡牌展示。
- 武将详情：相同台词对应多个分支文件时，顺序试听按台词去重，保留对局中的分支播放规则。
- 娜维娅：调整对局头像取景并更新对应的小尺寸平滑资源，保留原图。

## 安装与更新

1. 下载此版本的 Source code (zip) 并解压。
2. 备份本地修改，将解压目录内的扩展文件覆盖到 `extension/原神/`。
3. 确保 `extension/原神/extension.js` 存在，完全退出并重启游戏。

旧版玩家需要先手动安装本版本，之后才能使用游戏内的检查更新功能。新版仍需手动下载、覆盖并重启，不会自动替换文件。

本版本以无名杀 v1.11.6 为开发基准。已进行相关语法检查和单机测试，尚未完成网络更新提示及全部对局交互验证。
