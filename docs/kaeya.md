# 凯亚实装说明

- 男、魏、4体力，称号「寒风剑士」；技能顺序冷刃、藏锋。牌面文本按用户卡图保留，不接入语音。
- 冷刃对照本地原生「造成伤害时」节点使用 source:damageBegin2，在伤害扣血前询问。发动后连续两次各弃一张手牌或装备，每次重新检查在场及可弃牌；不排除属性杀连环传导，不按伤害点数重复。
- 藏锋将四张牌移入处理区并公开，拥有者在本地选择秘密牌；不在公开日志、牌标签或同步存储中记录秘密牌。对方强制选择1至4张，随后凯亚获得其余牌。
- 使用获得事件的 getg 快照识别是否拿中；拿中时仅弃目标当前手牌区仍保留的本次获得牌，不追踪已被其他效果移走的牌。先完成分牌，再弃牌，再用杀。
- 用户确认：藏锋生成杀无距离限制、不占正常额度、不受次数耗尽影响；选属性后对原目标直接使用，不重复选择目标或追加发动询问。仍检查使用禁令、目标合法性和在场状态。
- 属性以本地 lib.inpile / lib.inpile_nature 为依据，仅开放经典模式普通、火、雷，不引入特殊模式属性。没有实体素材，不伪造花色点数。
- 规则对照：本地 Player.canUse 第三参数 false 忽略距离，第四参数 false 不检查次数；Player.useCard(..., false) 不计次数。规则集转载 https://gltjk.com/sanguosha/rules/glossary/gamecard.html 、https://gltjk.com/sanguosha/rules/flow/condition.html 支持虚拟杀及非空闲时机的相应处理。属性三选一为用户额外明确确认。
- AI：冷刃评估拆牌效果；藏锋优先准备进攻并综合敌友、取牌价值、取得张数带来的命中风险、失去本批牌与冷刃后果。取牌AI不读取秘密牌或凯亚暗手牌。
- 完整原画位于 image/character/originals/kaeya.png；裁剪参数 kaeya-crops.json。独立导出选将400×480、对局500×750、详情900×1260，等比取景并轻度0.25px平滑；资源预览 docs/kaeya-portrait-review.jpg 已检查，未见明显密集点纹或线条断裂。未运行真实游戏三处界面，不能将资源检查视作对局实测。
- 简介及昵称来源：https://wiki.biligame.com/ys/凯亚 ，2026-11-23核对。
- tests/kaeya.mjs 为模拟技能流程及实际本地 canUse 方法体检查，覆盖分配、命中/未命中、移牌、离场清理、逐次弃牌、取消发动、角色注册、全武将非空称号简介。不替代真实对局及自动确认开关的界面测试。
