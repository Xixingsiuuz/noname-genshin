# 叶洛亚

- 男，群，4体力；技能顺序：巡夜、脱身。无语音配置。
- 巡夜在 useCardToTargeted 分别记录每个目标，弃牌可取消，取消只放弃弃牌，不放弃独立的结算后效果。每个拥有者对同一次用牌的同一目标最多记录一次。
- useCardAfter 检查所有在场及阵亡角色的伤害历史：伤害数量大于0、牌对象相同、最近 useCard 父事件相同。按当前回合角色起的座次处理对应记录。原目标离场不转移摸牌对象；无伤分支的摸牌及弃置使用者牌不依赖原目标仍在场。
- 标准天香修改原伤害的承受者，成功造成伤害后仍算此杀造成伤害；改版天香若取消原伤害并另造 nocard 伤害，则该新伤害不算此杀伤害。
- 脱身在 useCardToTarget 询问，仅取消自身目标；确认并再次校验成功后消耗本轮次数。暂时失效不清除次数，下一轮可再次发动。
- AI 按双方关系、当前牌价值、目标可能闪避及使用者可弃牌资源评估弃牌，摸牌对象与脱身收益在实际选择时重新计算。
- 简介与昵称来源：https://wiki.biligame.com/ys/叶洛亚 （2026-11-18核对）；称号沿用用户武将牌“魇夜燃芯”。
- 用户提供的宣传原图保存在 image/character/originals/illuga.jpg。tools/prepare_illuga.py 可重现三处独立裁剪，Lanczos缩放后0.25像素轻度平滑；目视检查脸部、上半身及衣物边缘，未见明显断点，原图印刷纹理仍保留。
- tests/illuga.mjs 为模拟测试，覆盖独立效果、转移伤害、阵亡伤者历史、多目标座次与计数、嵌套伤害排除、脱身限次与取消、全武将称号简介完整性。JavaScript语法检查通过。
- 未进行真实引擎对局、自动确认开关及三处界面实测；模拟测试不替代这些验证。
