# 储君&野心家

在身份设置中开启“储君&野心家”，下一局生效。规则已迁入无名杀本体，不依赖原神扩展；关闭扩展后仍可使用。配置位于 `noname/library/index.js`，身份入口位于 `mode/identity.js`，规则位于 `mode/identity-crown-path.js`。仅本地标准身份局启用；特殊身份、平民、联机及其他身份子模式不启用。关闭开关时不替换死亡处理。原有配置键和规则状态标识沿用，以保留既有开关设置；扩展内旧模块仅重导出原生模块，不再负责注册。

主公首轮出牌阶段可用“立储”，其他角色结束阶段也会询问。指定其他存活角色后全局消耗次数。忠臣储君死亡令在场主公失去1体力；忠臣储君强制继位，在原生终局检查及死亡清牌前获得原主公手、装、判中的两张牌（不足两张全部获得），获得自身武将的主公技，增加1体力上限并回复1体力。原主公改归忠臣阵营以随新主公结算胜负。继任主公不能重新立储。

忠臣储君弑君先调用与本地原生主公弑忠相同的 `modedDiscard(getCards("he"))`，不弃判定牌及扩展牌，再继位。

择途为不暂停的独立面板，最终点击时重新校验存活、人数和次数，以此时的当前回合角色绑定延迟转换。取消不消耗；确认后不可撤回。死亡清除待转换记录。人数不足时面板关闭。侍奉明主不主动公开身份；自立公开为野心家。野心家内部沿用内奸身份参与原生独立胜负和阵营AI计算，另存公开野心家状态；击杀奖励统一三张，不额外叠加反贼奖励。

AI在回合切换时按体力、手牌、主公状态及剩余反贼评估择途；立储目标按态度及体力评估。自立回复与摸牌按当前体力选择，飞扬评估负面判定与弃牌价值。

验证：`node tests/crown-path.mjs` 是节点模拟，覆盖开局挂载、继位、弃牌区域、主公技和奖励。已执行 JavaScript 语法检查。尚未真实对局验证；尤其需要检查择途在原生选择暂停期间的立即执行、跨回合点击、人数下降关闭、自动确认开关及界面布局。当前立即自立通过原生事件队列执行，若原生选择暂停，可能等待该选择结束，尚不能保证暂停期间即时结算。
